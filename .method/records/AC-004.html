Tactile : aucun accès au menu Pause de l'Arène

Origine
Audit de code (Claude, mode PO), 11/10/2026, branche lab-league-v3 au commit 3a493fc.
Impact / priorité
Moyenne (P2) : sur tablette ou téléphone, impossible de suspendre un match solo ni de quitter proprement depuis le jeu ; seul le retour du navigateur permet de sortir.
Localisation
Le menu ne s'ouvre que par l'action menu (Échap au clavier, Start à la manette) ou quand l'onglet est masqué (src/three/arenaView.js) ; le composant TouchControls de src/pages/arena/ArenaGame.jsx ne propose que tir, passe, sprint, tacle, geste, appel, pressing et changement de joueur.
Attendu
Un bouton tactile ouvre le même menu (pause réelle en solo, « le match continue » en ligne).
Travail
W-033.

Sur appareil tactile, le joueur ouvre le menu, suspend le match solo, reprend ou quitte sans clavier ni manette.

Constat établi par lecture du code (pas encore reproduit sur un appareil réel).
