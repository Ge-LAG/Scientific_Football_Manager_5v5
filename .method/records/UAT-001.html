W-002 à W-029. Candidat : branche lab-league-v3 (commits locaux, non poussés). Environnement : npm run build puis npm start → http://localhost:8787, ou après mise en ligne sur Hostinger (deploy/HOSTINGER.md).
Testeur / date
En attente : Guillaume.
Étapes et résultats attendus
  1. Ouvrir l'accueil sur un navigateur réglé en anglais : l'interface est en français. Passer en EN via le sélecteur, recharger : l'anglais est conservé.
  2. Scientifiques : les 16 personnages, leurs stats, postes, slogans et biographies sont identiques au prototype ; la fiche montre radar, power-up (effets Manager et Arène) et Réflexes.
  3. Labo Tactique → « Jouer contre les bots » : draft (choix manuel, « Choix auto », « Draft automatique »), composition (échange de joueurs, formation, stratégie), match en direct : changer de stratégie, déclencher un power-up, faire un remplacement, basculer vue tactique / vue Stade 3D, vitesse ×1/×2/×4 et pause ; rapport final complet.
  4. Arène → « Jouer » contre les bots : choisir son scientifique, coup d'envoi ; se déplacer (flèches), sprinter (Espace), tirer en chargeant (D), passer (S), lober, tacler, power-ups 1 et 2 (E, R), changer de caméra (C), menu (Échap), tableau (Tab) ; le schéma « clavier + souris » (ZQSD / WASD) reste disponible dans les réglages. Écran de fin avec notes.
  5. Créer un compte (pseudo + mot de passe uniquement), se déconnecter, se reconnecter ; profil : grade, XP, publications, historique ; changer le mot de passe.
  6. Deux ordinateurs (ou deux navigateurs différents) : salle Manager privée par code → draft → match → rapport avec XP et ELO (somme des variations nulle) → classement.
  7. Deux ordinateurs : Arène en partie rapide ; les deux joueurs se voient bouger ; quitter avec l'un : un bot reprend sa place ; rejoindre en cours de match.
  8. Recharger la page (F5) pendant un match en ligne : la partie reprend.
  9. Supprimer le compte de test depuis le profil.
  10. Nouveautés à évaluer : causerie de mi-temps (Manager), conseils tactiques, raccourcis 1–6, Championnat du Labo (5 journées, classement) ; dans l'Arène : entraînement guidé, ralenti des buts, appel de balle, crochet, mini-carte, effets visuels des power-ups ; commentaire vocal des buts ; écussons et couleurs débloqués par grade.
  11. Vague premium — contrôles : Réglages → Contrôles : schéma « Flèches + main gauche », disposition AZERTY puis QWERTY (les lettres du clavier visuel changent), réaffecter une touche puis revenir aux valeurs par défaut. En Arène : se déplacer aux flèches, sprinter (Espace), passe (S), tir chargé (D), lob, crochet (F), power-ups 1 et 2, sans le ballon : S = tacle, D = tacle glissé.
  12. Manette USB (Xbox ou PlayStation) : la manette est détectée dans les réglages, le test de vibration fonctionne ; en Arène : stick gauche, A passe, B tir, LB changer de joueur, RB / LT power-ups, RT sprint ; les libellés de l'aide passent en mode manette.
  13. Changement de joueur (Arène contre bots) : touche de changement (A sur AZERTY) ou clic sur le bandeau d'équipe ; on ne peut jamais prendre un coéquipier humain ; option « Suivre mes passes » dans le menu pause.
  14. Caméras 3D du Manager : pendant un match Manager, vue Stade 3D : réalisateur, latérale, tribune, frontale, ballon, joueur (choisir un scientifique), libre (glisser, clic droit, molette, flèches), boutons Proche / Éloignée, plein écran ; touche C.
  15. Vestiaire : personnaliser un scientifique (dont les 4 mulets et les 8 tenues), aperçu 3D (animations, cadrage visage), annuler / aléatoire / apparence d'origine ; en ligne (deux ordinateurs), l'adversaire voit l'apparence choisie (Arène : son scientifique ; Manager 3D : son équipe).
  16. Power-ups : page Power-ups (64, filtre par scientifique), fiche joueur (4 power-ups) ; choisir 2 power-ups avant un match Manager (composition) et en salle d'Arène ; en match, les deux se déclenchent séparément avec leur propre recharge.
  17. Rendu : sur votre machine, qualité Moyenne / Élevée / Ultra, compteur F3, banc d'essai #/bench ; appréciation « jeu premium » (lumières, animations, célébrations, filets, confettis).
  18. Vague 6 — caractéristiques : Vestiaire → Caractéristiques : répartir les points d'un scientifique (budget 612, préréglages Attaquant / Milieu / Défenseur / Gardien / Équilibré), vérifier la bio adaptée, l'archétype et le poste idéal ; revenir au profil d'origine (bio d'origine). La fiche du scientifique et la liste reflètent la répartition ; plus de note « overall ».
  19. Impact des stats : jouer deux fois le même scientifique en Arène avec une Vitesse très haute puis très basse (ou une Finition haute / basse) et constater la différence ; page Aide → « Impact des caractéristiques ».
  20. Gestes techniques (touche Geste technique + direction) : crochet, feinte de corps (sans direction), roulette (vers l'arrière), petit pont (défenseur devant), une-deux avec la paroi (vers la paroi), appui mural (contre une paroi, avec ou sans ballon) ; comparer un bon et un mauvais dribbleur.
  21. Défense : tacle (touche Tir quand l'adversaire a le ballon, ou touche dédiée) sans étourdissement ; pressing (touche Passe maintenue, ou touche dédiée) ; provoquer une faute : coup franc (distance, mur) et penalty dans la surface (tireur : orienter puis frapper ; gardien : plonger) ; aucun carton, y compris en Manager.
  22. Visages et coiffures : onglet Visage (forme du visage, forme des yeux, sourcils, nez) ; têtes adultes masculines ; coiffures réalistes, les 4 mulets dans la liste normale.
  23. Touches : en AZERTY puis en QWERTY, vérifier que chaque touche indiquée (réglages, aide en jeu, entraînement guidé, page Aide) déclenche bien l'action ; la touche en bas à gauche (W en AZERTY) fait du pressing et n'étourdit plus.
