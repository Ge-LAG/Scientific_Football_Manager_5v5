Revanche en ligne (Arène et Manager)

Sprint
Sprint 7 (M6) — Fiabilité et jeu à plusieurs
Résultat attendu
À la fin d'un match en ligne, chaque humain encore présent peut voter « Revanche ». Quand tous les humains présents ont voté (ou 30 s après le premier vote, avec les votants), le serveur crée une nouvelle salle privée avec les mêmes options, y fait entrer automatiquement les votants dans la même équipe ou du même côté (Manager : mêmes clubs, nouvelle draft), et affiche aux autres le code de la revanche.
Pourquoi (PO)
Enchaîner les matchs entre amis est au cœur de l'Arène (« parties courtes pour enchaîner ») ; aujourd'hui « Rejouer » ne marche qu'en solo et oblige à recréer un salon.
Périmètre et points d'entrée
Serveur : messages a.rematch et m.rematch dans shared/rooms/arenaRoom.js, shared/rooms/managerRoom.js (acceptés seulement en phase ended, une voix par membre), état rematch: { votes, code } dans stateFor ; création et entrée via createRoom / enter de shared/lobby.js. Client : boutons dans EndScreen de src/pages/arena/ArenaGame.jsx et dans src/pages/manager/ReportView.jsx ; navigation sur room.joined déjà gérée par src/game/GameProvider.jsx. Textes FR/EN.
Hors périmètre
Matchmaking public, classement des revanches, solo local (comportement actuel de « Rejouer » conservé).
Dépendances
W-034 recommandé avant (mêmes fichiers, tests réseau).
Vérification prévue
Tests unitaires avec clients factices (votes, délai de 30 s simulé, une seule salle de revanche par salle terminée, joueur parti non entraîné) ; étape ajoutée à scripts/smoke-online.mjs : les deux navigateurs cliquent « Revanche » → même nouveau code, mêmes côtés, le match démarre.
Points d'attention
Limiter les abus : une seule revanche par salle terminée, votes ignorés hors phase ended. XP et ELO normalement attribués pour le nouveau match. L'ancienne salle se ferme comme aujourd'hui.

Critères d'acceptation

Fin de match en ligne : bouton « Revanche » et compteur de votes visibles par tous les humains présents.

Tous les humains présents votent → nouvelle salle privée, mêmes options, mêmes équipes/côtés, entrée automatique des votants.

Après 30 s, la revanche part avec les seuls votants ; les autres voient le code et peuvent la rejoindre.

Une seule salle de revanche par salle terminée ; votes hors phase de fin ignorés (tests).

Smoke en ligne : revanche jouée à deux navigateurs ; textes FR/EN ; npm test et build verts.

Définition de fini commune : feuille de route, section « Définition de fini ». Statut cible après livraison : review avec preuves (l'acceptation reste à Guillaume).
