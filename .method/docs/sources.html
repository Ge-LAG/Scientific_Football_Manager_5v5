Metrics count Unicode characters in extracted context and the V5 method MD/JSON pair. They do not measure GPT-6 tokenization, reasoning, cached input, tool overhead or billing. Bootstrap excludes a real work package because none exists yet. The V5 baseline excludes absent PROJET state/plans. Metrics also report initial context including the raw START.html entry point, as loaded through native discovery. Inspect both scopes before comparing.

Evaluate comparable bugs, features, risky migrations and CTO handoffs on the same code baseline, acceptance criteria and model settings. Record actual input/output/reasoning usage where exposed, latency, accepted results, missed requirements and rework. Seek fewer unnecessary reads without lower quality. Character reduction is not promised invoice reduction.

Neither HTML nor English guarantees lower tokens for every passage. The structural gain is loading only relevant records. No embeddings service, extra model reviewer or model switching is imposed.

The scale probe creates disposable synthetic records with 50 active items and the rest archived. It checks exact bootstrap equality before/after growth, bounded history pages, searches, validation and health, recording timings. It tests corpus growth, not years of application evolution or real token billing. Durability regressions exercise changed criteria/code, expired rules, replacement chains, omitted constraints, revision conflicts and interrupted publication.
