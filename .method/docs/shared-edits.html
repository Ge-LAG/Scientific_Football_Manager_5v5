Protect shared edits

Use one writer per record. Independent work records can be prepared concurrently, but writes to shared sources and generated views go through the CLI. Read returns the full SHA-256; keep the candidate file outside docs/work/records/templates so it is not indexed. State returns a hash for project.json. Keep the hash from the version on which your edit was based.

python .method/tools/method.py read W-042
# Prepare an edited copy outside the canonical source directories.
# Increase data-revision by one; project.json uses revision.
python .method/tools/method.py replace work/W-042.html   --from-file candidate.html --expect ORIGINAL_FULL_SHA256

Replace checks the original hash, immutable ID/kind, revision increment, closure requirements, links and current state before committing. It atomically replaces the source and republishes the views. On conflict, re-read and merge the actual changes; fetching a fresh hash solely to force the old content through would lose work.

All CLI operations use a nonblocking OS file lock in .method.lock. Busy operations return a clear retry error. The OS releases the lock if a process dies; do not delete the lock file to bypass another writer. Each replacement uses a same-directory temporary file and an atomic rename.

A multi-file view publication uses .method-dirty. Readers refuse an interrupted publication. Reindex safely reconstructs views from canonical sources under the lock. This is crash detection/recovery, not an all-files database transaction; a source already atomically committed is retained.

The protocol protects cooperating CLI users. External editors, Git operations and copies can bypass it. Use direct edits only with exclusive ownership, then reindex and full validate. Shared branches/worktrees also require normal Git merge/review; a local file lock does not coordinate different machines.

New creates a unique draft without overwriting another record. Archived history is immutable through replace. For corrections, create a successor and retain historical evidence.
