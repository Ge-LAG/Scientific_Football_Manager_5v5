Définition de fini (chaque lot)
  1. Critères A1… du lot démontrés : tests automatiques ajoutés (tests/*.test.js, node:test) et, pour un changement visible, étape de script navigateur ou captures.
  2. npm test et npm run build verts ; aucune erreur console dans les parcours vérifiés.
  3. Interface en français et en anglais (clés dans src/i18n/fr.js et en.js, mêmes paramètres) ; aucune touche figée dans les textes (toujours useBindings()).
  4. Contraintes du profil respectées : aucune donnée personnelle, serveur qui fait autorité, entrées validées, 16 personnages d'origine inchangés.
  5. Fiche du lot mise à jour : preuves data-evidence-for (commande exacte, résultat observé, date, auteur), statut review (jamais accepted : l'acceptation revient à Guillaume) ; python3.11 .method/tools/method.py reindex puis validate --project-ready et health sans erreur.
  6. Vérifications sur un serveur de test dédié (port et fichier de données à part ; les scripts visent 8791 par défaut) ; ne jamais toucher le serveur de recette ni data/ réel.
  7. Tests de comportement plutôt que recherche de texte dans le code source ; aucune attente réelle de plus de 5 s dans npm test (délais injectables).
  8. Preuves : captures en JPEG (qualité ~75, moins de 200 Ko chacune) ; une preuve n'est « pass » que si la vérification a réellement été exécutée — sinon « pending » avec la raison.
