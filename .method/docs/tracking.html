Track a large project

Roadmap owns outcomes, milestones and dependencies. Work records own executable lots and evidence. project.json owns only current focus, next action and pointers to blockers, pending acceptance and external authority. Do not put session history or the whole backlog there.

Stable IDs: W-042 work, D-012 decision, TD-007 manual feedback, AC-009 code audit, REL-003 release, AUTH-002 authority. One record per independent item. Findings contain origin, impact/priority, reproduction/location, owner, linked work and status. Preserve TD/AC provenance even if one correction addresses both.

Severity defaults: critical = loss/corruption, exploitable flaw or blocked essential service; high = critical path failure with workaround; medium = material inconvenience; low = cosmetic/minor. Infer from impact. Routine triage needs no repeated PO approval; consult when priority changes product scope/mandate.

“Retour test dev” means collect/consolidate by default. Record TD items and return a French summary; implement if corrections are also requested or covered by the standing mandate. An explicit collection-only instruction remains collection-only.

Manual acceptance records steps, expected result, build/environment, tester and actual outcome. Link under pending_acceptance. A waiting PO test blocks only dependent work/release. Agent-run tests never impersonate PO sign-off.

At milestones, use a guarded replacement to mark reconciled closed history archived; retain files and stable IDs. Search excludes archives by default. Split large roadmaps by domain. Keep hot state to current pointers and use search when needed. Code and CI remain authoritative for implementation and logs.

Useful measures: milestone acceptance, blocked dependencies, escaped defects, recovery time and delivery lead time. Judge context reduction alongside acceptance quality/rework; fewer tokens help when the outcome stays correct.

At milestones, the CTO handles exceptions from health: stale decisions, evidence, dependencies and growth. No unchanged full-manual reread is required.
