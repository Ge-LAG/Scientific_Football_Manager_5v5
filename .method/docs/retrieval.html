Selective context, not full reloads

HTML enables navigation, not token compression. Raw HTML may cost more than Markdown. Savings come from short records, targeted retrieval, one canonical fact and bounded output. The local parser returns selected article text with link destinations, excluding layout.

python .method/tools/method.py context
python .method/tools/method.py context --task W-042
python .method/tools/method.py search "authorization tenant"
python .method/tools/method.py read security W-042
python .method/tools/method.py search "legacy export" --full-text --archive
python .method/tools/method.py new work W-042 --title "Short title" --summary "Outcome"
python .method/tools/method.py context --task W-042 --paths src/auth.py --manifest
python .method/tools/method.py health
python .method/tools/method.py state
python .method/tools/method.py reindex
python .method/tools/method.py validate

Omit .method/ inside the standalone kit. Python 3.10+ standard library only; no API key, model call, embeddings, package installation or remote index.

Context returns state, core, profile, selected work and its transitive mandatory constraints; ordinary hyperlinks are not expanded. Search ranks IDs/titles/tags/summaries and returns at most five metadata hits by default. It is lexical: try synonyms or --full-text before assuming absence. Body scanning stays local; only metadata is returned.

New creates a draft from a supplied template with unique ID and corrected links; it refuses existing IDs/files. Fill its content, set status and reindex. ID/title/summary are metadata, never executable commands.

Read extracts complete selected records, capped at 12,000 output characters by default. Over-budget requests fail without truncation. Read fewer records, split a growing record or deliberately raise --max-chars. Search defaults to 5,000 characters. These are character limits, not tokenizer counts.

Each reference includes path, ID and hash. Read checks the selected file hash; search/context use the inventory and file stamps. Reindex uses a disposable parse cache; full validate/health bypass it. Reindex after edits. Validate checks generated views, state references, HTML structure and local links; it does not check remote URL availability or test-claim truth.

Keep unchanged references already in context. Refresh state after meaningful changes/handoff; retrieve changed evidence. Hash checking stays on the host, without sending bodies to the model. After context loss, run context again. Previous summaries/cache do not prove current code.

One article should cover one decision/use case. Split when it repeatedly exceeds retrieval budgets. Full documentation audits remain legitimate scoped exceptions. Never let a default budget exclude an invariant needed for correctness.

See durability for archive partitioning and retrieval integrity boundaries.
