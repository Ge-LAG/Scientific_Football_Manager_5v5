Project profile

Produit/utilisateurs
Lab League — jeu de football 5v5 de scientifiques dans le navigateur : Manager 1v1 en ligne et Arène 5v5 à la 3ᵉ personne, bots si humains insuffisants. Vision : Vision/Vision.md. Parcours critiques : jouer vs bots sans compte ; salon par code ; compte pseudo+mot de passe.
Stack/carte
Node ≥ 20 (ESM). shared/ code isomorphe (données, moteurs, salons) ; server/ HTTP+API+WebSocket (ws), persistance fichier JSON data/ ; src/ client React 19 + Vite + Three.js. Rust archivé sous archive/ (inactif).
Plateforme
Navigateurs récents (Chrome, Edge, Firefox, Safari) ; hébergement cible Hostinger Cloud (app Node.js) ou VPS ; un seul port (PORT).
Commandes
Racine du dépôt : npm install ; tests npm test (node:test) ; build npm run build (→ dist/) ; dev npm run dev (Vite 5173 + serveur 8787) ; prod npm start puis GET /api/health = 200 ; E2E navigateur (Chrome/Edge sans interface, serveur lancé) node scripts/smoke-browser.mjs http://localhost:8787 smoke-out et node scripts/smoke-online.mjs … (deux navigateurs, comptes de test éphémères). Méthode : python3.11 .method/tools/method.py validate --project-ready (python du Store absent sur ce poste).
Contraintes
Aucune donnée personnelle : pseudo + mot de passe (scrypt) seulement. Serveur autoritaire, entrées validées, limitation de débit. Personnages, stats, descriptions et power-ups d'app.jsx conservés à l'identique (enrichissements séparés).
Git/livraison
Branche principale main ; commits uniquement à la demande du PO. Déploiement : deploy/HOSTINGER.md, autorité PO.
Langues
UI FR + EN, FR par défaut, choix persistant (localStorage + profil). Catalogues src/i18n/ ; contenu jeu shared/data/*.fr|en.js. Dates au format local de la langue choisie.
